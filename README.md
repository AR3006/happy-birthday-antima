# Romantic Birthday Website Template

A premium, fully static birthday microsite designed for GitHub Pages.

## Replace the sample photos

Put your real photos inside `images/` and update the filenames in `index.html`.

For the final version, you can use:
- photo01.jpg
- photo02.jpg
- ...
- photo30.jpg

## Add music

Place your MP3 here:

`music/birthday-song.mp3`

The Music button already points to that file.

## Personalize

Search `index.html` for:
- `Beautiful`
- `Dear you`
- birthday message
- signature

and replace the sample copy with your own.

## Deploy on GitHub Pages

1. Create a GitHub repository.
2. Upload everything from this folder.
3. Go to Settings → Pages.
4. Select the main branch and `/ (root)`.
5. Save.

No backend, database, build process, or Node.js is required.
